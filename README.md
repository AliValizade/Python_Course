# Python Course

A collection of Python programming assignments, exercises, and mini-projects covering fundamental programming concepts through practical applications.

## Overview

This repository contains coursework and programming exercises developed during a Python programming course.

The projects progress from fundamental Python concepts to more practical programming tasks, including object-oriented programming, file handling, data structures, and small application projects.

The repository also serves as a practical archive of Python programming exercises and examples that can be useful for learning and teaching.

## Course Content

The assignments cover a range of Python programming concepts, including:

* Python fundamentals
* Variables and data types
* Conditional statements
* Loops
* Functions
* Lists, tuples, sets, and dictionaries
* Strings
* File handling
* Exception handling
* Object-oriented programming
* Classes and objects
* Inheritance
* Modules
* Data persistence
* Practical mini-projects

## Selected Projects

### My Store

`Assignment 6/My_Store` contains a small store application implemented in Python.

It includes:

* `main.py`
* Data storage
* Basic application logic

### Media Management Mini Project

`Assignment 10 mini Project` contains a small media-oriented application with separate classes/modules for:

* Films
* TV series
* Actors
* Documentaries
* Media
* Clips

This project demonstrates object-oriented design and organizing a larger Python exercise into multiple modules.

### Rock Paper Scissors

`Assignment 8` includes a Python implementation of the classic Rock-Paper-Scissors game.

The same assignment also contains exercises involving:

* Complex numbers
* Fractional numbers
* Time
* Mathematical and graphical exercises
